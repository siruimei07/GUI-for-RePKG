# Wallpaper Field v1.2.1

v1.2.1 是基于 v1.2.0 的安全与发布完整性补丁，范围严格限定为维护路线图 WP1–WP4。

## 修复内容

- 在写入目标前统一规划 PKG 原始文件、TEX 可能派生文件、manifest 和 metadata，拒绝大小写冲突、文件/目录祖先冲突、Windows 保留名及源/输出重叠。
- 新建和更新输出共用可回滚事务；内容、unpack manifest 与 `metadata.json` 属于同一代提交。已覆盖第一个、中间和最终 metadata 动作失败，回滚后旧树路径与 SHA-256 不变。
- 引入统一 TEX decode budget，在分配前限制尺寸、像素、数量、压缩/解压/编码字节、单文件和批处理累计值；LZ4 必须精确匹配声明长度，DXT 必须具有完整块 payload。
- 修复 ImageSharp image/frame/sequence/stream 所有权、bounded C-string 消费语义和 RG88 equality/像素语义。
- SmokeTests 现在输出机器可解析的非零测试/断言计数，并提供失败退出码自检；Windows CI 显式执行真实 harness。
- 对外版本统一为 1.2.1，发布脚本默认在隔离目录生成自包含单文件 EXE、完整 ZIP、依赖 JSON、build manifest 和外部 SHA-256。

## 已知限制

- 本补丁不包含 WP5–WP11 的任务生命周期、问题中心、响应式/无障碍扩展或 Shell/View 重构。
- ImageSharp 保持在经过修补的 2.1.x 兼容线；2→4 主版本迁移需要独立 golden corpus 与内存基线，不属于本补丁。
- 更新操作保留无法证明归属的旧输出文件，不是严格目录镜像。
- 当前发布流程没有代码签名证书，候选物明确标记为 **unsigned**。请从可信来源取得 ZIP 并核对 SHA-256。
- 历史标签 `v1.0.0` 是不可构建的 broken/mis-tagged tag；它仅保留为历史记录，不应作为可发布基线。最早可靠的历史标签是 `v1.1.0`。

## 依赖审计（2026-08-20）

- NuGet vulnerability 扫描覆盖所有项目及 transitive packages，未报告已知漏洞。
- deprecated 扫描报告 ImageSharp 2.1.x 依赖链中的 `System.Runtime.CompilerServices.Unsafe 5.0.0` 与 `System.Text.Encoding.CodePages 5.0.0` 为 legacy transitive packages；没有可直接替换建议。
- outdated 扫描报告 Newtonsoft.Json 13.0.4、ImageSharp 4.1.1 及若干 transitive package 的新版本。v1.2.1 不做无关依赖迁移；尤其 ImageSharp 主版本升级仍按独立工作包处理。

## 版本与可追溯性

- 产品版本、FileVersion、manifest 与 ZIP 名：1.2.1（FileVersion/manifest 为 1.2.1.0）。
- AssemblyVersion 保持 1.0.0.0，以维持 v1.x 的托管程序集身份；它不是对外产品版本。
- InformationalVersion、`release-manifest.json` 和候选物均记录完整 40 位源 commit。
- ZIP 内含本项目与 RePKG 的许可/notice、RePKG 本地补丁记录、完整机器可读依赖清单和 release notes。

## 校验下载

在候选目录执行：

```powershell
Get-Content .\SHA256SUMS
Get-FileHash .\WallpaperField.exe -Algorithm SHA256
Get-FileHash .\WallpaperField-v1.2.1-win-x64.zip -Algorithm SHA256
Get-AuthenticodeSignature .\WallpaperField.exe | Select-Object Status, StatusMessage
```

两个计算结果必须与 `SHA256SUMS` 对应行一致；未签名构建的 Authenticode 状态应明确显示 `NotSigned`。`release-manifest.json` 还记录 SDK、RID、发布参数、EXE hash、签名状态和 `dependencies.json` 路径。
