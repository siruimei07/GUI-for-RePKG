# Wallpaper Field v1.3.0

v1.3.0 带来面向大型壁纸目录的项目浏览器、深灰与蓝色图库界面，以及图片预览、PKG 解包和 TEX 转换的安全与性能改进。

## 界面与浏览

- 方形封面配合紧凑间距和底部标题遮罩，一屏浏览更多壁纸；右侧常驻详情，在窄窗口中改用可关闭的详情面板。
- 深灰背景、蓝色当前项和清晰的键盘焦点；扫描、图库、项目浏览与问题中心使用一致的控件和文本层级。
- 项目浏览支持标题/Workshop ID 搜索、类型与问题筛选，以及名称、ID、类型排序；保留 3–6 列回收式虚拟化。
- 当前详情、键盘焦点与批量选择独立。隐藏选择明确计数，仍参与批处理；Space 切换选择，Enter 打开详情，窄窗 Escape 返回原焦点。
- Website 项目可浏览但不输出；无效 video 引用不会回退为 PKG 解包。

## 性能与任务状态

- 目录发现和扫描服务在后台执行，界面继续响应；已经完成、取消或被替代的扫描不再接收过期进度。
- 批量选择通过索引定位浏览项，避免每个项目都重新遍历整个列表。
- 搜索复用稳定排序结果；问题徽标改变时，仅在问题筛选影响成员集合的情况下重建网格。
- 滚动和尺寸事件复用正在进行的图片加载，减少反复取消和重复解码。

## 安全修复

- GIF 预览在解码前验证每一帧的尺寸、画布边界、调色板和数据块，并限制帧数及累计像素，拒绝“小画布、大帧尺寸”的异常输入。
- 扫描与图库的静态预览采用有界读取、文件身份与重解析点检查，限制输入体积、尺寸及解码结果；发布冻结且不保留源文件的像素。
- PKG 限制路径深度、累计文件名元数据与路径规划内存，防止深路径和大量条目放大内存占用；现有路径穿越、大小写冲突、事务提交和回滚检查继续生效。
- TEX 图片转换在分配前核算源副本、画布及帧数据预算，并在读取阶段拒绝 GIF 画布与旋转后帧尺寸不匹配的输入。
- 图片编码使用 Windows 自带的 PNG/GIF 编码功能，移除 ImageSharp 运行时依赖；无需额外的图片库许可证。PNG 像素/透明度以及 GIF 帧顺序、旋转、延时和循环由回归检查覆盖。

## 验证与发布

Windows CI 执行 Release 构建、严格分析器、完整控制台 SmokeTests、故意失败退出码检查、NuGet 漏洞审计、源码隔离门禁与真实候选启动，并保存宽屏/窄屏 WPF 截图。测试命令是：

```powershell
dotnet run --project .\tests\WallpaperField.SmokeTests\WallpaperField.SmokeTests.csproj --configuration Release
```

成功时最后一行必须是 `SMOKE_RESULT tests=<正数> assertions=<正数> passed=1 failed=0`。本仓库未使用 Test SDK，`dotnet test` 的零测试结果不能替代此检查。具体通过结果以本次发布关联的 CI 为准。

发行文件为 Windows x64 自包含 ZIP，内含 EXE、许可证、第三方说明、发布说明、来源 commit、依赖清单和校验数据。无需安装 .NET 或单独的 RePKG。仓库根的历史 EXE 不是本次发布的下载入口。

## 兼容性与限制

- 支持 Windows 10/11 x64；源码构建需要 .NET 10 SDK。Linux 云环境可交叉编译，但不能运行 WPF 界面或 Windows 专属测试。
- 保留既有设置、metadata 格式、只读扫描、逐项错误隔离和安全事务解包行为。
- 项目浏览显示静态首帧；扫描与图库支持受限制的 GIF 动画。异常或超预算图片显示占位。
- Windows 系统高对比度与减少动态效果继续生效。真实辅助技术、不同物理 DPI 和低端设备的体验仍需对应设备验证。
- 本社区发行包未附商业代码签名；请核对下载来源及 SHA-256。

## 下载校验

```powershell
Get-Content .\SHA256SUMS
Get-FileHash .\WallpaperField.exe -Algorithm SHA256
Get-FileHash .\WallpaperField-v1.3.0-win-x64.zip -Algorithm SHA256
```

两个文件的散列应与 `SHA256SUMS` 对应行一致。`release-manifest.json` 记录准确的源码 commit、工具链、文件大小和签名状态。
