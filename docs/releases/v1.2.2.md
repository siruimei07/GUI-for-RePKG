# Wallpaper Field v1.2.2

v1.2.2 完成维护路线图 WP5–WP11：在保留 v1.2.1 安全解包与事务输出边界的基础上，补齐可取消任务、独立问题中心、输入预防、无障碍、深页面/应用模块、性能预算和受控 RePKG 上游面。

## 用户可见改进

- 扫描、解包和输出库刷新都有可见、可键盘触发的取消入口；窗口关闭会先请求取消并等待安全提交或回滚，不在任务仍写盘时强制退出。
- 扫描或图库刷新失败、取消时保留上一份可用快照；解包只取消已确认提交成功项目的勾选，失败或取消项保留重试上下文。
- 新增常驻“问题中心”第三页。扫描与图库页显示紧凑摘要；问题中心可按严重度、来源和文本筛选，复制选中/全部问题、清理已解决项、打开日志/输出目录、导出脱敏诊断并查看版本身份。
- 路径输入共享即时验证；源/输出重叠、reparse point、Windows 保留设备名、尾点/空格和不可访问状态会在主操作前给出可行动反馈。`project.json` 与 `metadata.json` 在解析前受 4 MiB 预算保护。
- 扫描页增加名称、仅可处理、仅有问题组合筛选，以及“选择当前匹配”“清除选择”；过滤不会丢失隐藏勾选。Comfortable/Compact 密度在扫描和图库间共享并持久化。
- Compact、Regular、Wide 三档布局不再隐藏刷新或取消等唯一入口。三页各自拥有固定控制区和独立虚拟化列表，程序定位只滚动目标列表。
- 页面标题、紧凑导航与无文字按钮具有稳定辅助功能名称；黑、白、Signal Yellow 表面使用双层焦点；High Contrast 使用系统颜色；Windows 减少动态效果会同时停用非必要界面动画并让 GIF 使用静态首帧。

## 数据、安全与状态

- PKG 继续只通过 `SafePackageReader` 流式读取；原始与 TEX 派生输出仍在写盘前完整规划，事务 staging/commit/rollback、资源预算和逐项失败隔离保持不变。
- 解包进度现在区分规划、提取、提交、回滚和完成阶段，并在可计算时报告 entry/byte 工作量；未知工作量使用真正的不确定状态。
- 结构化逐项结果记录 `Committed`、`NotModified` 或仍可能有副作用的磁盘事实。重复输出目标在写盘前拒绝。
- 日志按 2 MiB 轮换，最多保留当前文件加四个归档并清理超过 14 天的自有归档；路径默认使用指纹脱敏。问题详情和可见记录均有明确上限。
- 输出图库递归发现输出根下的 `metadata.json`，跳过 reparse point、`unpacked`、staging 和 backup。候选按规范化相对路径稳定排序；同一 Workshop ID 的重复候选整组排除，并在问题中心列出全部冲突路径。

## 架构与维护

- 扫描、解包、图库和问题状态分别由 `ScanSession`、`UnpackSession`、`LibrarySession`、`ProblemCenterSession` 所有；单一 `TaskLifecycleCoordinator` 管理前台任务 ID、取消、提交临界区和静止等待。
- 扫描、图库和问题中心已拆为独立深 `UserControl`；主题按 Tokens、Accessibility/Motion、Base Controls、Domain Components 四层加载，旧 `EndfieldTheme.xaml` 只保留兼容合并入口。
- 1000 卡片/问题 fixture 固定了首个 WPF idle、筛选、连续滚动、问题加载/复制和 UI 热路径零同步文件 I/O 预算。只有实测 I/O 硬门禁路径被修改。
- 产品源码只通过 `WallpaperField.ThirdParty.RePKG` 第一方适配器接触 RePKG。`RePKG.Application` 的实际编译输入由可验证的职责规则从 24 项收窄到 16 项；完整上游源码、许可和 notices 仍保留。`RePKG.Core` 的 42 项源码保持显式未裁剪状态。

## CLI 与测试入口

自动截图/回归入口支持 `--source`、`--output`、`--scan`、`--page scan|library|problems`、`--snapshot`、`--width`、`--height`、`--scroll-index` 和 `--reduced-motion`。缺值不会吞掉下一个 flag；首个合法重复值生效；未知、重复或非法参数进入问题中心。宽高必须是有限正数且不大于 16384。

真实回归门禁是 console Smoke harness：

```powershell
dotnet restore .\WallpaperField.slnx --configfile .\NuGet.Config
dotnet build .\WallpaperField.slnx -c Release --no-restore
dotnet run --project .\tests\WallpaperField.SmokeTests\WallpaperField.SmokeTests.csproj -c Release --no-build --no-restore
dotnet run --project .\tests\WallpaperField.SmokeTests\WallpaperField.SmokeTests.csproj -c Release --no-build --no-restore -- --verify-failure-exit
```

当前 SmokeTests 不是标准 Test SDK 项目；本版本实测 `dotnet test WallpaperField.slnx` 退出 0 但执行 0 项，因此不能代替上述机器摘要和故意失败退出自检。

## 兼容性与已知限制

- `Version` 为 1.2.2，`FileVersion` 与应用 manifest 为 1.2.2.0；`AssemblyVersion` 继续保持 1.0.0.0，以维持 v1.x 托管程序集身份。
- settings 和 metadata 保持向后兼容。新 `DisplayDensity` 字段缺失或非法时回落 Comfortable；现有嵌套图库继续按递归契约发现。
- 更新操作仍保留无法证明归属的旧输出文件，不是严格目录镜像；需要完全干净结果时请使用新的空输出目录。
- ImageSharp 主版本迁移仍不属于本补丁；完整图像 golden corpus、dispose 与峰值内存基线应在独立工作包中完成。
- 当前发布流程没有代码签名证书。候选物必须明确标记为 **unsigned / NotSigned**；请从可信来源获取完整 ZIP 并核对 SHA-256。
- 自动化已覆盖 WPF 资源、键盘焦点、High Contrast 映射、reduced-motion、96/144 DPI 渲染和多个窗口尺寸；真实屏幕阅读器、物理 200% DPI、SmartScreen 与干净 VM 仍需人工验收，不能由自动化结果推断通过。

## 版本与下载校验

发布脚本把 `InformationalVersion` 固定为 `1.2.2+<完整 40 位源提交>`。分发 ZIP 内含 EXE、release notes、根 LICENSE/notices、RePKG license/notices/本地补丁记录、`release-manifest.json` 和完整 `dependencies.json`；外部 `SHA256SUMS` 同时记录 EXE 与 ZIP hash。

```powershell
Get-Content .\SHA256SUMS
Get-FileHash .\WallpaperField.exe -Algorithm SHA256
Get-FileHash .\WallpaperField-v1.2.2-win-x64.zip -Algorithm SHA256
Get-AuthenticodeSignature .\WallpaperField.exe | Select-Object Status, StatusMessage
```

两个计算结果必须与 `SHA256SUMS` 对应行一致；本版本未签名候选的 Authenticode 状态应为 `NotSigned`。
