# Wallpaper Field v1.4.0

v1.4.0 是一次界面大改版：整套界面换成明亮的「终端浅色」风格，恢复并扩展了 v1.2 时代的丰富动效，同时修复若干稳定性、性能与易用性问题。扫描、解包、输出库和问题中心的行为与数据格式保持不变。

## 全新界面

- 明亮的纸面工作区，配合近黑色的 L 形边框：左侧导航栏、顶部标题栏与底部状态栏把内容区包在中间。整体参考明日方舟式的工业信息界面，但全部为原创绘制，不含任何官方徽标、角色、字体或素材。
- 单一青色信号色用于选中、当前页、主要操作与进度；亮绿色只表示「可处理 / 已就绪」，琥珀色表示警告，红色表示错误，问题严重度一眼可辨。
- 方角几何与切角标记：按钮、卡片、面板、输入框、复选框和下拉框统一为方形，主要命令带有切角标记，悬停时出现边缘标记线。
- 每页左上角有页码（01–04）与中英双语小标题，舞台右下角印有淡色大号页码，标题栏同步显示当前页码。
- 扫描操作区、问题摘要、统计读数、空状态与问题卡片全部按浅色主题重做；输出库路径条使用黑色信息条，项目浏览的批量处理托盘作为底部黑色操作栏。
- 窗口改为方角（Windows 11 下同样不再自动圆角）。

## 动效回归

- 切换页面时，新页面从右侧滑入，同时一道带青色前缘的黑色扫掠条横过舞台，页面各区块依次升起出现。
- 舞台背景是缓慢漂移的蓝图网格；状态灯呼吸闪烁；右上角校准环缓慢旋转，任务进行时加速。
- 扫描、解包或刷新进行中，舞台顶部会出现持续滚动的警示条纹。
- 按钮悬停轻微上浮，导航项悬停向右平移；指针离开后动画自动归位，不残留动画时钟。
- 「减少动态效果」（Windows 设置或 `--reduced-motion`）会关闭以上所有动效；项目浏览页内部保持静止，只保留页面级切换效果。

## 修复与优化

- Windows 10 图标修复：图标字体增加 Segoe MDL2 Assets 回退，Windows 10 上不再显示方框。
- 高对比度：新增的所有语义颜色都映射到系统颜色；装饰层（网格、页码水印、校准环、警示条纹）在高对比度下自动隐藏。
- 每次进入输出库都会重复登记同一批警告的问题已修复，问题中心的开放问题数不再越刷越多。
- 日志写入失败时，相关问题记录改为在界面线程登记，避免后台线程修改界面集合。
- 预览图读取失败后不再在每次滚动时反复重读和记录同一张损坏图片。
- 扫描与解包进度更新时不再重复刷新全部按钮状态，大型目录处理时界面更流畅；扫描卡片的项目标识改为缓存，减少问题中心更新时的重复计算。
- 扫描失败原因更具体：链接或重解析点、文件过大、没有权限、Workshop ID 重复等情况会分别说明。
- 从资源管理器「复制为路径」粘贴的带引号路径、首尾空格会被自动整理。
- 启动失败时显示包含日志位置的提示，而不是静默退出；未处理异常对话框不会层层叠加；截图模式下出错直接以非零代码退出。
- Windows 注销或关机时也会保存源目录、输出目录和卡片密度设置。
- 网站类型项目的提示改为与版本无关的「当前版本暂不支持网站输出」。

## 验证与发布

Windows CI 执行 Release 构建、强制重新编译的严格分析器、完整控制台 SmokeTests、项目浏览器响应式与视觉状态矩阵、故意失败退出码检查、NuGet 漏洞审计、源码隔离门禁与真实候选启动。测试命令：

```powershell
dotnet run --project .\tests\WallpaperField.SmokeTests\WallpaperField.SmokeTests.csproj --configuration Release
```

成功时最后一行必须是 `SMOKE_RESULT tests=<正数> assertions=<正数> passed=1 failed=0`。具体通过结果以本次发布关联的 CI 为准。

发行文件为 Windows x64 自包含 ZIP，内含 EXE、许可证、第三方说明、发布说明、来源 commit、依赖清单和校验数据，无需安装 .NET 或单独的 RePKG。仓库根的历史 EXE 不是本次发布的下载入口。

## 兼容性与限制

- 支持 Windows 10/11 x64；源码构建需要 .NET 10 SDK。
- 保留既有设置、`metadata.json` 格式、只读扫描、逐项错误隔离和安全事务解包行为。
- 界面字体使用系统自带的 Bahnschrift、微软雅黑与 Cascadia Mono/Consolas；缺少时自动回退，不随程序分发字体。
- 映射网络驱动器与 SUBST 盘符上的预览身份校验仍可能拒绝显示预览，计划在后续版本改进。
- 真实辅助技术、不同物理 DPI 和低端设备的体验仍需对应设备验证；发现的问题将在 v1.4.1 修复。
- 本社区发行包未附商业代码签名；请核对下载来源及 SHA-256。

## 下载校验

```powershell
Get-Content .\SHA256SUMS
Get-FileHash .\WallpaperField.exe -Algorithm SHA256
Get-FileHash .\WallpaperField-v1.4.0-win-x64.zip -Algorithm SHA256
```

两个文件的散列应与 `SHA256SUMS` 对应行一致。`release-manifest.json` 记录准确的源码 commit、工具链、文件大小和签名状态。
